# Eigenspace Stress Decomposition & CMBR Invariant Trading Engine

A quantitative research and execution engine for extracting the invariant "Cosmic Microwave Background" (CMBR) of the S&P 500 cross-asset manifold and trading orthogonal residual dislocations.

---

## 1. Mathematical Architecture

### 1.1 Return Manifold Construction
Given adjusted close prices for $N \approx 500$ S&P 500 constituents over a 15-year period:
1. Log returns:
   $$r_{i,t} = \ln\left(\frac{P_{i,t}}{P_{i,t-1}}\right)$$
2. Rolling standardization across lookback window $T = 252$ trading days:
   $$z_{i,t} = \frac{r_{i,t} - \mu_i}{\sigma_i}$$
3. Empirical correlation matrix $C \in \mathbb{R}^{N \times N}$:
   $$C = \frac{1}{T} Z^T Z$$

### 1.2 Random Matrix Theory (Marchenko-Pastur Noise Filtering)
Under the null hypothesis that $C$ is generated by pure random noise, its eigenvalues are bounded by:
$$\lambda_{\max} = \sigma^2 \left(1 + \sqrt{\frac{N}{T}}\right)^2, \quad \lambda_{\min} = \sigma^2 \left(1 - \sqrt{\frac{N}{T}}\right)^2$$
where $\sigma^2 = 1 - \frac{1}{N}\sum_{k \in \text{signal}} \lambda_k$.

* **Noise Bulk ($\lambda \le \lambda_{\max}$):** High-frequency microstructure noise (TV static).
* **Signal Eigenspace ($\lambda > \lambda_{\max}$):** The persistent structural **CMBR Modes** $V_{\text{signal}} = [v_1, v_2, \dots, v_k]$:
  - $v_1$: Market Mode (aggregate systemic liquidity / beta, explaining ~46% of total market variance).
  - $v_2, v_3, \dots, v_k$: Sector / Duration / Macro Rotation dials (Utilities, Financials, Real Estate, Energy).

### 1.3 Orthogonal Manifold Projection
Each day, the market return vector $\mathbf{r}_t \in \mathbb{R}^N$ is orthogonally projected onto the clean structural subspace:
$$\hat{\mathbf{r}}_t = V_{\text{signal}} V_{\text{signal}}^T \mathbf{r}_t$$

The idiosyncratic dislocation vector is:
$$\mathbf{e}_t = \mathbf{r}_t - \hat{\mathbf{r}}_t = (I - V_{\text{signal}} V_{\text{signal}}^T)\mathbf{r}_t$$
where $\hat{\mathbf{r}}_t$ represents what collective systemic manifold structure demanded the stocks do, and $\mathbf{e}_t$ represents the asset's orthogonal dislocation.

### 1.4 Dislocation Signal State Machine
Computes the rolling cumulative Z-score of the residual dislocation:
$$s_{i,t} = \frac{\text{CumResidual}_{i,t} - \mu_{e,i}}{\sigma_{e,i}}$$

* **Long Signal:** $s_{i,t} < -2.0$ (Asset stretched downward relative to the manifold).
* **Short Signal:** $s_{i,t} > +2.0$ (Asset stretched upward relative to the manifold).
* **Exit / Flat:** $s_{i,t}$ crosses back through $0.0$ (Mean-reversion complete).
* **Stop-Loss / Regime Break:** $|s_{i,t}| > 4.0$ (Structural link broken, immediate liquidation).
